# R05 云端语言偏好

本阶段用界面语言验证跨设备同步。账户认证按 [邮箱账号配置](R05_ACCOUNT_SETUP.md) 接入。

1. 在 Supabase 项目的 SQL Editor 执行 [语言偏好迁移](../supabase/migrations/20261118000100_account_language.sql)。已有 CLI 迁移流程的项目可沿用该流程部署同一文件。
2. 登录后打开「我的 → 云端语言偏好」，主动查看云端值。选择「保存当前语言到云端」上传本机当前语言，也可选择「使用云端语言」更新本机语言。
3. 在第二台设备使用同一账号登录，确认可读取并应用该偏好。换用另一个账号检查其偏好独立。测试时可在两台设备先读取同一版本，再保存不同的值，确认后保存的一方看到冲突提示和最新值。
4. 「清除云端语言」会清除该账号的语言值，并保留版本号以拒绝来自旧设备的过期更新。

表的行级安全策略按当前会话用户隔离读取。写入通过数据库函数校验会话身份和预期版本。重试已经完成的相同写入可返回现有版本。

## 体重和腰围同步

1. 部署 [身体记录迁移](../supabase/migrations/20261118000200_account_body_measurements.sql)。
2. 登录后打开「进度 → 打开账号身体记录」。在账号视图里可以新增测量，也可以用「复制本机记录」把设备记录复制到该账号在当前设备上的工作区。
3. 选择「手动同步 → 授权并同步」读取该账号云端记录并上传待同步改动。在第二台设备登录同一账号、同步并核对记录。
4. 在两台设备把同一天改成不同的值，再确认同步。冲突时选择采用云端版本，或者保留此设备版本并再次确认同步。验收删除传播和断网后重试。

每个账号工作区独立保存，退出或切换账号时页面会回到设备记录。首页继续读取设备记录。

## 已完成训练历史同步

1. 部署 [训练历史迁移](../supabase/migrations/20261118000300_account_workout_history.sql)。
2. 完成一条本机训练并登录。打开「训练 → 打开账号训练历史 → 复制已完成训练 → 确认复制」，将本机已完成的训练复制到此设备上的账号历史。重复复制会跳过本机已经导入过的训练。
3. 选择「手动同步 → 授权并同步」。在第二台设备使用同一账号授权同步，检查训练日期、动作、组数、重量、次数、RIR 和备注。换一个账号检查记录隔离。
4. 展开一条训练，选择「删除账号副本」并确认。授权同步后，在另一台设备再次同步，确认账号副本被移除。断网时待同步的记录和删除操作保存在设备上，恢复网络后可再次授权同步。

账号历史和本机训练日志分别保存。进行中的训练、训练计划、恢复记录和进度照片使用设备存储。云端训练条目使用独立的随机标识。删除清除训练内容并保留该标识，用于阻止旧设备重复上传。

## 每日营养目标与饮食记录同步

1. 部署 [营养同步迁移](../supabase/migrations/20261118000400_account_nutrition.sql)。
2. 登录后打开「营养 → 打开账号营养日志」。可在此新增、编辑或删除食物并编辑每日目标，也可用「复制本机营养数据」导入历史饮食记录和尚未设置的每日目标。复制操作保存到此设备上的账号日志。重复复制会跳过已经导入过的本机条目。
3. 选择「手动同步 → 授权并同步」。在第二台设备登录同一账号并授权同步，检查日期、餐次、数量、合计和目标。断网时可继续编辑，恢复网络后再次授权同步。
4. 在两台设备分别编辑同一条饮食记录或每日目标，再同步。发生冲突时，可采用云端版本，或保留此设备的版本并再次授权同步。记录删除也会同步。最后换用另一个账号确认数据隔离。

本机营养日志、账号营养日志和各账号之间的记录分别保存。首页营养卡继续读取本机日志。

## 数据导出和账号注销

1. 在前四项迁移之后部署 [数据管理迁移](../supabase/migrations/20261118000500_account_privacy.sql)。沿用邮箱验证码登录配置。
2. 打开「我的 → 管理我的数据 → 导出本机记录」。安卓选择保存文件夹，浏览器下载 JSON。检查档案和计划版本、训练、恢复反馈、饮食、测量及照片索引。照片原图在「进度照片」里逐张导出。
3. 登录后选「导出账号记录」，核对该账号的云端数据及此设备的账号副本。待同步记录包含在 `deviceAccountWorkspace`。导出的 JSON 为明文。
4. 用专用测试账号执行「注销账号并删除云端数据 → 发送注销验证码 → 验证并永久注销」。确认该账号及其已同步数据被移除、其他账号和本机设备日志仍可用。注销同时撤销旧会话继续刷新的能力。离线副本和已导出的文件由设备或文件的持有人管理。

服务器校验会话归属及最近五分钟内的 OTP 验证，并通过外键在同一事务内删除账号同步的数据。当前应用的照片保存在各设备上。
